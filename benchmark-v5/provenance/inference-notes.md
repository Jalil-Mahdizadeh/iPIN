# Native inference details and scope

These adapters preserve the released predictors' evaluation semantics. No training, threshold fitting on tests, architecture replacement or test-based checkpoint choice is performed.

- **iPIN / native PLM-interact:** byte-identical frozen model code, strict state loading and saved-DEV oracle tests. The native comparator is the Bernett/Leakage-Free release, not the separate HumanV11 checkpoint available in some containers. Full sequences and mean AB/BA logits match the previous iPIN comparisons. All 52,048 existing native original-test predictions are retained byte-for-byte in the reused array; only 24,870 new ILP-negative pairs were inferred.
- **TUnA:** released Bernett model with full ESM2-150M residue embeddings. The pinned upstream model's block masks and pooling allow exact independent endpoint features at evaluation. Its released singleton evaluation is the oracle: direct multi-pair native mean-field broadcasting would create unintended cross-pair outputs. Cached scoring preserves each singleton's uncertainty-adjusted probability. Native evaluation recomputes a GP covariance buffer from released precision; trained parameters remain unchanged. All 2,784 reused sequence features match exact sequence identities, frozen manifests and fresh numerical checks; 238 were computed here.
- **RAPPPID:** released `1690837077.519848_red-dreamy` multiplicative head, trained on STRING C3; this is not a reconstruction of the paper's concatenation-head checkpoint. Use deterministic released SentencePiece encoding, native 1,500-residue leading cap, zero padding, singleton recurrent embeddings and singleton-equivalent head standardization. Direct native head batching would mix the mean/std across pairs. Native singleton probability is the numerical oracle, with no learned-state changes.
- **X-PAIR:** separately evaluate `interaction_bernett` and `multitask_xfair`. Checkpoint metadata confirms their respective Bernett and X-fair source paths. Shared full FP32 Ankh-Large residue features follow unmodified upstream extraction. Cache only the independent linear projection; cross-attention and interaction heads remain unchanged. Native full forward, swaps and heterogeneous 64-pair batches are numerical oracles. Checkpoint training length filters were 0–2,000 residues for Bernett and 50–2,000 for default; benchmark inference retains all full sequences. Published X-fair training/validation overlap remains after applying the default checkpoint's length filters.
- **SPRINT:** unchanged native HSP construction, followed by native serial arithmetic with qualified stable filtering of unused destination entries (see `SPRINT-EXECUTION-ADDENDUM.md`). The parallel prediction binary has unsynchronized accumulation in a shared score matrix; it is not used. The 64-thread HSP constructor is qualified against the native serial constructor in the verified image. Sorting HSP blocks changes only inter-block order, preserving every native record and within-block order. One v5 TRAIN sequence has length 12; the native constructor deliberately emits its full self-HSP, which the benchmark parser accepts and preserves. No test sequence has this issue. The scorer consumes all 350,382 TRAIN-positive edges. Candidate routing labels are constant dummy markers, discarded before matching the actual frozen truth.

Exact sequence overlap auditing does not prove complete checkpoint history or exclude homology and PLM pretraining exposure. X-PAIR default's exposed rows are reported separately, with identical conservative exclusion masks applied to all predictors as a secondary analysis. RAPPPID and X-PAIR Bernett exact processed training membership remain unavailable locally.

- **D-SCRIPT addition:** original human_v1, native Bepler–Berger lm_v1 encoder, existing length-safe positional extension and halo-preserving tiled contact maps; all learned parameters and pooling are unchanged. Full coverage and native numerical qualification passed. Known supervised training overlap is disclosed. See `DSCRIPT-ADDENDUM.md`.
