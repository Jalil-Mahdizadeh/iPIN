# D-SCRIPT addition, 2026-10-05

The user asked during the running benchmark whether D-SCRIPT could be included. Add the original released `human_v1` checkpoint as a ninth predictor. This addition was chosen after seven neural predictors' point estimates and intervals had been inspected, but before any D-SCRIPT scores on these tests. No other checkpoint selection, test membership, metric, bootstrap setting or result is changed.

Use the existing `dscript-native-arm64-v1.sif` (D-SCRIPT 0.3.1), original `human_v1` weights and native Bepler–Berger `lm_v1` encoder. Reuse exact-sequence projected residue features where their checkpoint and cache hashes match. This is inference only.

The image's unmodified predictor has a 2,000-element nonlearned positional index. An already qualified local compatibility adapter extends that index and tiles contact-map computation with the native convolution's complete halo. It preserves full sequences, learned parameters and global pooling; no test rows are cropped or dropped. Fifty test proteins exceed 2,000 residues, affecting 2,301 original-test pairs and 2,237 ILP-test pairs. Label this implementation as original D-SCRIPT with length-safe execution. Check supported-length predictions against unmodified native inference and tiled computation against the same complete-map formula before scoring. For longer sequences, unmodified upstream inference fails, so numerical identity to an upstream long-sequence output cannot be claimed.

Score the same 76,918-pair union once, including self-pairs; map scores to both 52,048-pair tests. Scores are native generalized-sigmoid probabilities. Audit known public human training exposure and flag it; add common pair-unexposed and endpoint-unexposed sensitivity subsets for all nine predictors. These additional subsets are specified before D-SCRIPT inference results and are descriptive, not model-selection criteria. The original eight-model protocol remains archived verbatim in `PROTOCOL.md`.
