# Vx-128 full TRAIN/VAL continuation

Authorized 10 October 2026: use two complete four-GPU nodes (eight GPUs) for original Bernett TRAIN/VAL. This fits the small Vx evidence and quality/profile classifiers; PLM-interact and MSA Pairformer remain frozen. No shuffled arm, TEST features/evaluation, backbone fine-tuning, new pooling, or hyperparameter search is included.

## Fixed scientific contract

- All 163,192 original TRAIN pairs and 59,260 original VAL pairs, including unsupported examples; source rows are checked against the original CSVs. No later homology exclusions are substituted.
- Original accession matching, monomer cache cap 4,096, depth at most 127 homologs plus query, masks, joint redundancy filter, minimum eight homologs, 50% coverage requirements, 1,536-residue combined limit, reliability gate, layer 15, 128 global features, random projection and AB/BA averaging. Import the immutable original implementation. No alignment rescue or padding to force depth.
- Reuse verified original monomer caches and exact Vx feature artifacts where input identity is reproduced. Stream the same checksum-pinned archive for remaining TRAIN/VAL proteins. Reuse the already computed held-out sequence exclusion hashes; do not open TEST data or predictions.
- Native VAL predictions use full sequences, mean AB/BA logits, FP32 parameters, BF16 autocast, TF32 off. Reuse verified benchmark-v1 VAL predictions. Any original VAL rows absent from that audited subset require qualified native inference under the same contract; incomplete baseline coverage blocks fitting.
- Exactly two TRAIN-only fits: original StandardScaler, full PCA32 and logistic regression (C=0.1, lbfgs, max_iter=1000, seed 20261007), on all eligible TRAIN pairs. Quality/profile uses the original 68 features and requires no additional Pairformer forward. Native TRAIN logits are not fitting targets or inputs.
- Preserve the original whole-component DEV assignment for all 3,711 VAL proteins. Choose each fusion alpha only on calibration pairs from [0, 0.1, 0.25, 0.5, 1], with the smallest tied value. Cross-boundary pairs never select alpha. Assessment does not select models or parameters.
- Primary assessment is the assigned assessment pairs outside the original 4,000-pair pilot VAL sample. Report all assessment, calibration, crossing and full VAL populations, plus original pilot rows and fixed length/coverage/depth strata. Newly evaluated rows can share proteins/families with previously inspected rows; this remains exploratory confirmation, not an independent blind dataset.
- Matched protein Poisson bootstrap, endpoint-product weights, 1,000 replicates, seed 20261007. Useful predictive gain requires primary AP improvement >=0.010 over native with lower 95% bound >0, AUROC loss <=0.005, and a positive AP interval over quality/profile. No true-versus-shuffled condition is imposed: this is a practical prediction objective, explicitly different from the pilot's pairing-specific continuation rule.
- Exact native fallback is used for biological unavailability. Missing/corrupt computational output, CUDA failures or incomplete coverage abort analysis; they never become fallback. Every frozen row must have a valid output before either classifier is fitted. Heads are fitted once, without automatic retry or subset rescue.

## Execution and limits

Preparation and qualification reuse the current interactive allocation; the main job requests exactly two exclusive nodes, four GPUs and 288 CPUs per node. Eight independent workers each use one GPU; no gradient synchronization or distributed neural training is required. Fixed length-balanced shards, atomic compressed feature chunks and checksums make completion auditable. Within-job reuse validates every chunk; a failure stops the whole job. No automatic requeue or second submission.

Main allocation ceiling: 28 hours, 224 allocated GPU-hours and 16,128 allocated CPU-core-hours. Reserve two hours for fitting/verification/shutdown. Preparation/qualification ceiling: four hours in the existing one-GPU, 72-CPU allocation; charge all elapsed allocation time attributable to this task, including idle time. New storage ceiling: 80 GB. These limits are separate from completed pilots. Label-free timing with a 1.5 safety factor must fit before submission. Only compact features are stored, not full pair tensors.

Preflight verifies source hashes, completed pilot compatibility, original feature reproduction, symmetry, frozen layers and forbidden output heads, representative lengths, unit/integration tests, exact baseline coverage and all eight shard memberships. Freeze inputs/code before submission. Final verification independently reconstructs predictions, calibration choices and bootstrap intervals, checks TRAIN-only transforms and source/feature provenance, and samples new pair inputs across fixed length/depth bins for replay. No new outcome-dependent changes after freezing.

The run ends after the full TRAIN/VAL report and verified heads. TEST remains a separate future decision regardless of the result. Status: [STATUS.md](STATUS.md), or `python -B retrain-vx/scripts/status.py` from the repository root.
